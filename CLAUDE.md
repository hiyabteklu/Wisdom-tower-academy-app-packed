# Instructions for Claude agents

Before doing anything in this repository, read **`docs/HANDOVER.md`** (newest state and next tasks), then `HANDOFF.md` in full and follow its **MANDATORY AGENT PROTOCOL** (section 0), then read `STATUS.md` (live checklist, owner decisions, session log). Then `docs/PENDING_PATCHES.md` (owner report and session log not yet copied into `STATUS.md`, plus the causes behind the navigation fixes), `NATIVE_APP_BRIEF.md`, `ARCHITECTURE.md`, `docs/BUILD_PITFALLS.md`, `docs/SUPABASE_NOTES.md` (verified database facts: tables, policies, constraints), `WEBSITE_CHANGES.md`.

Work on one task at a time. Before you stop (or when your quota is nearly out), update `STATUS.md`: session log, checklist, and any new owner decisions. Write the log first. If your tool cannot resend a file as big as `STATUS.md`, add a dated entry to `docs/HANDOVER.md` instead.

The repo is public: never commit secrets or personal data. The owner is not a coder: explain in plain language.
