# Instructions for Claude agents

Before doing anything in this repository, read `HANDOFF.md` in full and follow its **MANDATORY AGENT PROTOCOL** (section 0), then read `STATUS.md` (live checklist, owner decisions, session log). Then **`docs/PENDING_PATCHES.md`** (owner report and session log not yet copied into `STATUS.md`, plus exact edits to `MainActivity.kt` that are still to be applied: do those first if your tools can patch files), `NATIVE_APP_BRIEF.md`, `ARCHITECTURE.md`, `docs/BUILD_PITFALLS.md`, `docs/SUPABASE_NOTES.md` (verified database facts: tables, policies, constraints), `WEBSITE_CHANGES.md`.

Work on one task at a time. Before you stop (or when your quota is nearly out), update `STATUS.md`: session log, checklist, and any new owner decisions. Write the log first.

The repo is public: never commit secrets or personal data. The owner is not a coder: explain in plain language.
