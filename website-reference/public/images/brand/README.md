Brand / logo assets

Upload with **exact** names:

| File | Use | Recommended size |
|------|-----|------------------|
| `logo.png` | Header logo (primary) | **256×256** or **512×512** square PNG with transparent background |
| `logo.svg` | Optional vector version | Same mark |
| `logo-mark.svg` | Favicon / square icon source | Square |
| `og-cover.jpg` | Social share | **1200×630** |

**Path:** `public/images/brand/`

Header looks for `/images/brand/logo.png` first. If missing, it falls back to the “WT” / “WA” badge.
