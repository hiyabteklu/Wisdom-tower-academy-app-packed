## 2. Verified facts

Real data shapes, counts, the ECE scope quirk, policies and renderer names are in **`docs/CONTENT_SHAPES.md`** (N0 audit, 2026-10-11). Key points:
- All hub content = rows of `public.learning_resources`; published rows are readable with the public key; progress tables are own-rows-only.
- Flashcards / quizzes / exams live in `meta` JSON (`cards[]`, `questions[]`, `durationMin`), notes in `body_md`, PDFs as `appwrite:<id>`. No video or life-saver rows existed when checked.
- Quiz/exam text and flashcards contain `$math$`, `[[term]]`, `==highlight==`: ONE shared local rich-text + KaTeX renderer serves notes, flashcards, questions and solutions.
- ECE rows are ALL stored under `ece/sem-1/<slug>` with package `ece-y3-sem-1`, also for Semester 2 courses: query both semesters' scope paths (copy `listResources` in `website-reference/src/lib/content.ts`).
- PDFs: view URL = `{ENDPOINT}/storage/buckets/{BUCKET}/files/{FILE_ID}/view?project={PROJECT}` (website `/api/content/pdf` does the same; role "Any" has READ; cut the id at `|`). Needs endpoint, project id, bucket id in the app: check `.env.example` for which are `NEXT_PUBLIC_*` (the bucket id may be server-only: then ask the owner to expose it, or use the website proxy for PDFs only).
- Progress and results to write (own rows): `learning_progress` (upsert on `user_id,resource_id`), `exam_attempts`, `academic_results`: copy `saveProgress`, `saveExamAttempt`, `getScopeStats` from `website-reference/src/lib/content.ts`.
- Course page path -> `scope_path` (website hub pages): `/academy/freshman/<s>` -> `freshman/<s>`; `/academy/remedial/<s>` -> `remedial/<s>`; `/academy/grades/<g>/<s>` -> `grade/<g>/<s>`; `/academy/special-packages/<slug>/<sem-1|sem-2>/<course>` -> `ece/<sem>/<course>`; COC/UAT/GAT -> `coc` / `uat` / `gat` (hub aliases not checked yet); Entrance Questions -> `entranceScope(stream, subject, year)`. Native helper: `contentScopePath(basePath)` in `StudyWorkspaceScreen.kt`.
- Tracker scope id (2026-10-11, verified in `website-reference/src/app/academy/*/[resource]/page.tsx`): the id the website hub page passes to `HubContentView` as `trackerScopeId`, written to `academic_results.scope_id` when an exam is submitted: Freshman `freshman-<subject>`; Remedial `remedial-<subject>-<hub>`; Grades `grade-<g>-<s>-<hub>`; ECE `special-<slug>-<sem>-<course>-<hub>`; COC/UAT/GAT `coc-<hub>` etc.; Entrance `entrance-<stream>-<subject>-<year>-exams`. Native helper: `trackerScopeIdFor(basePath, hubId)` in `StudyWorkspaceScreen.kt` (only the first four; the others still use the website page).
- Access rules (2026-10-11, session M, from `website-reference/src/lib/content-locks.ts`, `data/content-availability.ts`, `lib/ownership.ts`, `components/ResourceHubGrid.tsx`): the six hub cards of a course follow ONE lock mode (`open`, `require_purchase`, `coming_soon`): first an admin row in `public.content_locks` (public read; key `scope:<scope_path>`, else `package:<package id>`; the stored mode `locked` shows as coming soon), else the static rule per path. `open` = everybody; `coming_soon` = nobody ("Coming soon" pop-up); `require_purchase` = signed-in student who owns the package (free mode: everybody signed in). Native code: `data/content/ContentAccess.kt`.
