1. **Account Tab**: Replace guest gate with website Sign In / Sign Up tabbed form; implement flip-able Student ID Card; render 3 numbered verification sections; fix vertical text wrapping; deduplicate welcome toast.
2. **Hub Depth**: Create native `StudyWorkspaceScreen` containing the 6 Learning Hub cards (Books, Short Notes, Flashcards, Question Banks, Exams, Life Savers) and History block; copy `hubs/*.jpg` to assets; wire all package/subject routes to reach it natively offline.
3. **Packages & Package Details**: Remove invented subheaders in PackagesCatalog; implement stream/semester grouping for Freshman (Natural/Social, Sem 1/2), ECE (Sem 1/2), Grades 9–12, and Branch detail screens matching website.
4. **Learning & Settings**: Update `LearningScreen` to match `LearningContent.tsx` course cards with progress bars; update `SettingsScreen` to remove invented accordion and restore website forms.
5. **Native Feel**: Add smooth `AnimatedContent` fade-through for bottom tabs and slide transitions for nested screens; optimize cold-start initialization.
