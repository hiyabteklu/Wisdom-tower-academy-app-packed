- 2026-10-12 | WHAT F1b DOES: while a native hub screen (list, notes, flashcards, quiz, exam, PDF) is shown, every non-local WebView that is VISIBLE is set INVISIBLE (the browser then stops drawing it and throttles its timers) and `onPause()` is called; when the screen is left, exactly those WebViews are set back to VISIBLE and resumed. `pauseTimers()` is deliberately NOT used (it is global and would stop the exam timer and math rendering). A side effect that should also help: an INVISIBLE view receives no touches, so no touch can fall through to the website page.
