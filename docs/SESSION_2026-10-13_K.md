# Session log 2026-10-13 K: one notification settings place (Settings), drawer dialog removed

> Continues `docs/SESSION_2026-10-13_J.md`. Repo is PUBLIC: no secrets.

- 2026-10-13 | Claude (chat) | IN PROGRESS: owner request (two screenshots): "two notification settings, one in Settings and one in the drawer. Take what is unique from the drawer, add it to Settings, then remove the drawer one. Make it functional."
  - Root cause / facts found by reading the code (not compiled):
    - Drawer dialog `NotificationSettingsDialog` (`MainActivity.kt`) has 4 switches stored by `AcademyNotificationManager` (prefs `wta_notification_prefs`): Study Timer Rewards, Planner & Deadlines, Daily Goal Nudges, Academy Announcements. These are REAL: `notifyStudyTimerCompleted`, `notifyPlannerTaskDue` (also used by the planner alarm receiver), `notifyDailyGoalNudge` check them, and `AcademyFirebaseMessagingService` only shows a push when Announcements is on.
    - Settings section "Notifications & Study Alerts" (`SettingsScreen.kt`) has 3 switches (Daily Study Goal Reminder, Exam & Syllabus Updates, Weekly Performance Digest) stored in `wt_settings_prefs` under `notif_daily_study`, `notif_exams`, `notif_weekly_digest`. Nothing in the app reads those keys (searched the whole repo): they were cosmetic.
    - No code anywhere sends a weekly digest.
  - Plan: one patch script (MainActivity.kt is huge, SettingsScreen.kt is about 35 KB): Settings gets the two unique switches (Study Timer Rewards, Planner & Deadlines) and its Daily Study Goal Reminder / Exam & Syllabus Updates switches are wired to the real keys (goals / announcements). The drawer row, heading, dialog and its helper are removed; the website bridge `openNotificationSettings` now opens the Settings tab.
