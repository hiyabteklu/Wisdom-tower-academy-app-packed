## What changed (website repo `main`, one commit `1ec5a0c`)
- NEW `NotificationAudiencePicker.tsx`: chips Everyone, the eight registration levels (from `ACADEMIC_LEVEL_OPTIONS`), any other level text students typed (from the live counts), and the admin's custom audiences. Several chips can be chosen (union). Each chip shows a live student count; below the chips a line shows how many students the current choice reaches and how many have no level saved ("only Everyone reaches them"). "Custom audience" form: name + levels (+ optional package ids, comma separated); a custom chip has a delete button. It calls the live functions `admin_audience_level_counts`, `admin_count_notification_audience`, `admin_list_notification_audiences`, `admin_add_notification_audience`, `admin_delete_notification_audience` with the admin's own session (signatures read in `docs/sql/notifications_v2.sql`).
- `NotificationComposerV2.tsx` (whole file resent): audience step is now "Groups of students" (the picker, empty = everyone) or "One student (user id)". The confirm box names the count. The success message no longer says "Students reached: 0" for a broadcast (the server returns `recipients: 0` for "everyone"; it now says "Everyone can see it").
