## Root cause (found from the owner's `e: file:///` line)
The KDoc header of the placeholder file contained the text `data/competition/*`. In Kotlin a slash-star inside a comment opens a NESTED comment, so the KDoc was never closed. My own mistake in session 2026-10-15 A. The patch script was never involved (it was not run; `MainActivity.kt` is unchanged).

## Fix
Rewrote the header as `//` line comments with no slash-star sequence. Pushed in the commit that adds this file. Not compiled by me; the next CI run is the test. Hypothesis: green.

## Pitfall to remember (not yet added to `docs/BUILD_PITFALLS.md`, the file is big; add it with the next failed or green build)
Never write a slash followed by a star inside a Kotlin comment (for example in a path like `data/competition/*`); Kotlin comments nest, so it leaves the comment unclosed. Use `//` comments or write the path without the star.
