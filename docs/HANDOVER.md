## 4. Tool limits learned (for chat-based agents)

- GitHub MCP tool can only replace whole files: fine up to about 40 KB, not for `MainActivity.kt` (244 KB), `GuidesScreen.kt` (about 55 KB) or reliably for `STATUS.md` (38 KB). It cannot push `.github/workflows/*` and cannot delete files. Code search only sees the default branch (to read a branch use `get_file_contents` with `ref=refs/heads/<branch>`). Workaround that WORKS (proven by run #2): push a Python patch script into `scripts/` with exact anchors that must each match once and an idempotent marker comment, then the owner runs the generic workflow.
- The sandbox has no internet and no Kotlin compiler: only the owner's GitHub Actions build proves anything compiles. Always say "not compiled" until the build is green AND the owner tested on the phone.
- `AuthStateManager.refreshIfNeeded` is a `suspend` function: it cannot be called from a button click without a coroutine scope.
