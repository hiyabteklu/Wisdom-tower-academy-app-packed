## 4. Tool limits learned (for chat-based agents)

- GitHub MCP tool can only replace whole files: fine up to about 40 KB, not for `MainActivity.kt` (244 KB), `GuidesScreen.kt` (about 55 KB) or reliably for `STATUS.md` (38 KB). It cannot push `.github/workflows/*`. Big files fetched by it are saved to `/mnt/user-data/tool_results/` and can be grepped there. Workaround that works: push a Python patch script (exact anchors, each must match once, idempotent marker) into `scripts/` and let the owner run it through the patch workflow.
- The sandbox has no internet and no Kotlin compiler: only the owner's GitHub Actions build proves anything compiles. Always say "not compiled" until the build is green AND the owner tested on the phone.
- `AuthStateManager.refreshIfNeeded` is a `suspend` function: it cannot be called from a button click without a coroutine scope.
