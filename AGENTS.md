# Instructions for AI coding agents

Before doing anything in this repository, read `HANDOFF.md` in full and follow its **MANDATORY AGENT PROTOCOL** (section 0), then read `STATUS.md` (live checklist, owner decisions, session log). Then **`docs/PENDING_PATCHES.md`** (owner report and session log not yet copied into `STATUS.md`, plus patches that are written but not yet applied: do those first if your tools can patch files), **`docs/EDITING_LARGE_FILES.md`** (how to change a file that is too big to resend whole: patch script in `scripts/` + the GitHub Action; never stop at "the file is too big"), `NATIVE_APP_BRIEF.md`, `ARCHITECTURE.md`, `docs/BUILD_PITFALLS.md`, `WEBSITE_CHANGES.md`.

Work on one task at a time. Before you stop (or when your quota is nearly out), update `STATUS.md`: session log, checklist, and any new owner decisions. Write the log first.

The repo is public: never commit secrets or personal data. The owner is not a coder: explain in plain language.
